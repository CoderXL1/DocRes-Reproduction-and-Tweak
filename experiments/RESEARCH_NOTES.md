# 显式任务条件与输出头拆分

- 记录日期：2026-10-12
- 状态：结构改动仍为研究假设与实验计划，尚未实现或训练验证；平滑实验入口已通过真实权重 MPS 冒烟验证，尚未形成定量结论。
- 范围：DocRes 的任务条件、输出表示、多任务训练与去畸变坐标场平滑消融；不属于本次 CUDA → MPS 推理适配。

## 1. 问题与当前实现

DocRes 把文档图像与三通道 DTSPrompt 拼接，使用一个 Restormer 和一个三通道输出头完成五种任务。输入的前三通道始终为图像，后三通道的语义随任务变化。

当前代码的含义如下。表格中的通道顺序按实现填写，不按论文公式的列举顺序填写。

| 任务         | DTSPrompt 三通道           | 有效输出                                        | 监督           |
|--------------|----------------------------|-------------------------------------------------|----------------|
| dewarping    | x 坐标、y 坐标、文档 mask  | 归一化 backward-map 残差 Δx、Δy；第三通道不使用 | 前两通道 L1    |
| deshadowing  | 背景估计的三个颜色通道     | 去阴影图像的三个颜色通道                        | L1             |
| appearance   | 初步增强图像的三个颜色通道 | 增强图像的三个颜色通道                          | L1             |
| deblurring   | 梯度图重复三次             | 清晰图像的三个颜色通道                          | L1             |
| binarization | 阈值图、梯度图、初始二值图 | 两类 logits；第三通道不使用                     | 前两通道交叉熵 |

关键代码：

- [模型 forward](../models/restormer_arch.py)：接受 `task` 参数，但函数体不使用它；因此任务条件主要由 DTSPrompt 承载。
- [数据与目标构造](../loaders/docres_loader.py)：去畸变目标使用 `bm_shift = (bm * size - getBasecoord(size, size)) / size`，并与 mask 拼成三通道标签；训练损失只读取前两通道。
- [各任务损失](../train.py)：去畸变、二值化只使用前两通道，其余三个任务使用完整图像输出。
- [推理与后处理](../inference.py)：去畸变把偏移加回基础坐标，上采样后通过 `cv2.remap` 从原图取像素。

## 2. 待验证的假设

### H1：任务身份与空间先验应当分别提供

DTSPrompt 同时承担任务辨别和空间先验两种作用。加入显式 task embedding，可能减少网络从 prompt 的统计模式辨别任务的负担，同时继续利用 DTSPrompt 的空间信息。

不同 prompt 的结构确实提供了辨别线索，例如坐标渐变、重复梯度通道、近似二值图。但这种可辨别性在不同图片和分布变化下是否稳定，需要实验确认。

### H2：共享输出头可能带来额外的任务竞争

相同输出位置跨任务分别表示带符号的坐标残差、颜色值或分类 logits，目标范围和损失形式均不相同。拆分输出头可能改善优化与语义隔离。

这只是可能的机制，不能据此断言已经发生梯度冲突。共享 backbone 仍可能出现任务竞争；拆分输出头并不消除所有多任务干扰。

### H3：共享图像特征仍然有价值

各任务均涉及文档的文字边缘、背景、纹理与颜色。保留共享 backbone，测试能否保留多任务收益，同时减轻任务条件和输出表示上的负担。

论文表 2 中，TDD 去模糊的单任务 baseline 为 28.95 dB，DocRes 为 27.35 dB，说明统一设计存在性能取舍；这组比较本身不能证明差异由梯度冲突造成。[DocRes，表 2](https://arxiv.org/html/2405.04408)

## 3. 两个独立改动

### A. 显式 task embedding

- 为五种任务分配独立 ID 和可学习 embedding。
- 保留原始图像与 DTSPrompt 输入。
- 优先测试将 embedding 投影为特征通道偏置，并广播加到 patch embedding 的输出上；初始实验只在这一处注入，避免同时改多个层级。
- 以后再比较更强的特征调制方式，避免第一轮实验同时引入复杂结构。
- 推理接口显式传入任务；检查 task 参数确实被消费。

### B. 按输出类型拆分 heads

初始方案为三个输出头：

1. geometry head：2 通道，预测归一化 Δx、Δy。
2. image head：3 通道，供去阴影、外观增强、去模糊共享。
3. binary head：2 通道，预测二分类 logits。

使用已知 task 显式选择 head。保留 backbone、DTSPrompt、标签构造和任务损失。后续可再比较五个任务各自一个 head，检验图像恢复任务之间是否也需要隔离。

注意：head 选择本身已经提供显式任务信息。因此该实验测试的是“任务路由与输出头隔离”的组合收益，不应解释成纯粹的参数隔离收益。

## 4. 第一轮对照实验

| 组别 | DTSPrompt | 显式 embedding | 输出头 |
| --- | --- | --- | --- |
| B0 | 保留 | 无 | 原共享 3 通道头 |
| B1 | 保留 | 有 | 原共享 3 通道头 |
| B2 | 保留 | 无 | 按 task 选择三个类型头 |
| B3 | 保留 | 有 | 按 task 选择三个类型头 |

解释重点：B1 检验共享输出头下显式任务条件的作用；B2 检验路由与头拆分；B3 检验在已做 head 路由后，backbone 内部条件化是否还有额外收益。

控制条件：

- 固定数据划分、增强、采样比例、训练尺寸、评估后处理与推理尺寸。
- 使用一致的 backbone 初始化和可比的训练预算，记录每个任务实际接受的更新次数。
- 明确记录是否采用去畸变预训练；论文 §4.3 使用 50,000 步去畸变预训练，再进行 100,000 步联合训练。
- 新 geometry/binary head 可从原输出卷积前两通道复制初始化，image head 可复制完整输出卷积；新增 embedding/投影单独记录初始化方式。
- 不因结果好坏临时改变 loss 权重。若要调整权重，应作为独立实验。
- 记录新增参数量、训练耗时、推理耗时与内存，不把更多参数的收益自动归因于设计更优。
- 条件允许时使用多个随机种子，并报告均值和波动。

测量项：

- 按任务分别报告官方评估指标，避免只看总体平均。
- 在共享参数上测量不同任务梯度的范数和余弦相似度；比较时记录 AMP 缩放及 loss 尺度。
- 用同一图片生成不同任务的合法 prompt，观察任务控制行为；再用错配 prompt 做受控压力测试。
- 比较正确 task ID + 错配 prompt 的表现，区分任务指令与先验质量的影响。该测试属于分布外诊断，不能单独作为性能结论。
- 检查小样本任务是否失去联合训练收益，以及几何任务和内容恢复任务是否相互影响。

## 5. 为什么去畸变保留坐标输出

一个进一步的问题：能否让所有任务都直接回归修复后的图像，从而统一输出语义？可以设计这样的模型，但输出语义统一并不保证任务更容易。

几何去畸变改变的是内容的空间位置。输出位置 `(u, v)` 对应的颜色来自输入的另一个位置 `(x, y)`；图像内容恢复任务通常在基本相同的栅格上修改颜色或局部纹理。

当前去畸变采用 backward mapping：

```text
M(u, v) = 基础坐标(u, v) + Δ(u, v)
修复图像(u, v) = 从原图的 M(u, v) 位置插值采样
```

直接 RGB 回归需要把几何对应与细致纹理的重建同时交给网络。显式坐标场加采样则把“去哪里取像素”交给网络，把颜色采样交给确定的插值算子。这是对几何任务的结构约束，不是对其可解性的保证。

本项目还有明确的分辨率优势：网络只在 256×256 上预测坐标场，之后将坐标场上采样到原图尺寸，并从高分辨率原图采样。直接在 256×256 上回归 RGB，再把结果放大，会缺少原图中没有进入低分辨率输入的文字细节；直接高分辨率 RGB 回归则增加模型计算和内存成本。

限制同样需要记录：低分辨率坐标场可能遗漏局部几何细节；错误映射和插值可能损伤文字；被遮挡或原图已经丢失的内容无法仅靠采样恢复。坐标输出也不等于完整的外观修复。

该解释结合了当前代码与几何建模分析，不能当作论文证明了直接 RGB 回归必然失败。[DewarpNet §4.1](https://openaccess.thecvf.com/content_ICCV_2019/papers/Das_DewarpNet_Single-Image_Document_Unwarping_With_Stacked_3D_and_2D_Regression_ICCV_2019_paper.pdf) 也采用预测 backward map 后采样的结构。

## 6. 后续可选实验：统一最终图像监督

保留 geometry head，通过可微采样器生成修复图像，再在训练时增加对齐后的图像重建监督。这样可以统一部分最终评估/监督形式，同时保留几何表示。

- 可微采样需要在 PyTorch 内完成；当前 NumPy / OpenCV 推理后处理不能直接承担反向传播。
- 需要与目标在几何、裁剪、曝光和颜色上可比较的配对标签。若光照不同，直接像素损失可能同时惩罚几何与外观误差。
- 首先单独比较坐标损失、图像损失及两者组合，注意采样梯度与低纹理区域中的几何歧义。
- 直接 RGB 去畸变应作为独立表示消融，并保持可比的分辨率与计算预算。

## 7. 去畸变坐标场平滑消融

- 补充日期：2026-10-14。
- 状态：独立实验入口已实现，并于 2026-10-17 完成真实权重 MPS 冒烟验证；系统性消融和定量评估待执行，见 [实验说明与验证记录](dewarp_smoothing/README.md)。

### 7.1 当前行为与待验证假设

[去畸变推理](../inference.py) 取模型输出的前两通道作为坐标残差，加回基础坐标后，对完整的归一化 backward map 连续执行 15 次以下操作，再上采样到原图尺寸并调用 `cv2.remap`：

```python
pred = cv2.blur(pred, (3, 3), borderType=cv2.BORDER_REPLICATE)
```

这一步对 x、y 两个坐标通道分别做均值滤波，加入映射应当在空间上平滑变化的先验。待验证的假设是：模型预测中存在局部坐标误差波动，平滑可以减轻矫正后的文字波纹或局部扭曲，但过强的平滑也可能削弱真实的局部形变，并在边界处引入偏移。

后处理的存在不能证明作者对模型“不自信”，也不能证明模型在不同训练种子或重复推理中的统计方差较大。邻域坐标差异包含正常的几何变化，不能直接视为预测噪声；需要结合几何误差与最终图像质量判断。

### 7.2 第一阶段：固定 checkpoint，仅改变平滑次数

| 组别 | 3×3 均值滤波次数 | 用途 |
| --- | --- | --- |
| S0 | 0 | 加回基础坐标后直接上采样，检验无平滑的表现 |
| S1 / S3 / S5 | 1 / 3 / 5 | 检验较弱平滑是否足够 |
| S10 | 10 | 检验接近当前设置的较弱平滑 |
| S15 | 15 | 当前实现的基线 |
| S30 | 30 | 检验更强平滑是否出现过度平滑 |

控制条件：

- 使用同一 checkpoint、数据划分、输入预处理、MBD mask、推理精度和设备，不重新训练。
- 对每张图片缓存同一次前向得到的坐标残差与基础坐标，每个组别从同一份未平滑映射的副本开始，避免把不同组别的滤波次数累加。
- 固定核大小、`BORDER_REPLICATE`、坐标归一化与缩放方式、上采样和 `cv2.remap` 插值方式、输出尺寸；只改变滤波次数。
- 优先比较独立 dewarping 的输出，避免后续去阴影、外观增强影响归因。输出使用无损格式，所有组别保持一致。
- 在验证集选择平滑次数，选定后在独立测试集评估；不根据测试集结果调参。

### 7.3 测量与可视化

- 最终效果：沿用去畸变评估协议的官方指标；若有文字转写标签，额外报告同一 OCR 引擎与配置下的 CER / WER。
- 几何精度：若有与预测采用相同坐标约定、裁剪和有效区域的 backward-map 标签，报告平滑前后的坐标端点误差，并分别统计内部与边界区域。
- 空间平滑性：报告坐标场二阶差分的幅度，作为局部变化的诊断；该值越小不代表几何精度越好。若有坐标标签，同时分析预测误差场的局部波动。
- 映射异常：统计越界采样比例与局部 Jacobian 行列式非正的比例，并说明坐标方向及有效区域约定；用于检查局部退化或折叠。
- 视觉检查：对所有组别使用相同的预先选定样本和文字局部裁剪，展示文字基线、细笔画、强弯曲区域及页面边缘；同时展示坐标网格或误差图，避免只挑选改善样本。
- 成本与稳定性：记录平滑及完整去畸变耗时，报告逐图配对差值、整体均值与分布；条件允许时用按图片重采样的 bootstrap 给出差值置信区间。

### 7.4 判断依据与后续实验

- 若 S0 较差、适度平滑同时改善几何指标和最终图像指标，支持“局部预测波动需要抑制”的假设，但不据此推断作者动机或模型的统计方差。
- 若较少次数达到或优于 S15，说明当前平滑强度可能并非最优；若 S30 损害局部几何或文字质量，则记录平滑与细节保留的取舍。
- 若平滑主要改变边界表现，后续单独比较“平滑完整坐标场”与“只平滑残差后加回基础坐标”，使用一致的核、次数和边界策略，检查基础坐标在边界处被滤波的影响。
- 若收益在不同图片上差异较大，按形变强度和边界区域分层分析，再考虑自适应平滑；不在本轮同时改变滤波器类型。
- 若后续希望减少后处理依赖，可另开训练实验，在坐标监督外加入空间正则项，并同时评估无平滑与固定平滑的结果。对完整坐标场直接施加一阶平滑惩罚可能压缩正常坐标梯度，需要单独论证正则形式与权重。
- 第一轮 B0–B3 结构对照仍固定使用 S15，保持后处理一致；之后再交叉比较各结构的 S0、S15 和验证集选定设置，检验结构改动是否改变平滑需求。

## 8. 实施边界

- 新结构需要训练或微调，原 checkpoint 不能直接获得新增条件化机制的收益。
- 可以复用部分 backbone 和输出卷积权重，但仍须验证训练稳定性与任务效果。
- 本记录不启动训练，不修改模型、训练数据或损失实现。
